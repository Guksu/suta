| 항목 | 내용 |
|------|------|
| 날짜 | 2026-11-26 |
| 작성 | 에이전트 |
| 관련 경로 | `docs/research/2026-11-26-*.md`, `evals/benchmark/fidelity/`, `scripts/benchmark/archive.mjs`, `scripts/lib/runArchive.ts`, `demo/src/tests/runArchive.test.ts`, `docs/benchmark.md`·`benchmark.en.md` |

## 1. 개요

사용자가 suta를 "고객이 원하는 UI를 만들어 주는 구독형 제품"으로 키우기 위해 세 방향(논문에 근거한 색 조합, 전문성이 느껴지는 레이아웃과 모션, 말한 디테일까지 구현하는 구현력)의 깊이를 요청했다. 먼저 세 갈래를 조사했고, 세 조사가 모두 "지난 벤치마크의 생성물이 남아 있지 않아 직접 확인하지 못했다"에서 막혔다. 그래서 첫 구현으로 벤치마크 생성물을 저장소에 보존하는 단계를 더했다.

## 2. 작업내용

- 조사 문서 3개를 썼다(서브 에이전트 3개 병렬, 코드 변경 없음).
  - `docs/research/2026-11-26-color-science.md`: 색 공간·조화·대비·색각 이상·어두운 테마·차트 색의 근거와 구현 후보 15개.
  - `docs/research/2026-11-26-layout-motion-depth.md`: 지금 값의 지도, 빠진 것, 지난 실행 재집계, 구현 후보 14개.
  - `docs/research/2026-11-26-fidelity.md`: 지난 판정 재분석과 "요구 충족률" 측정 설계.
- 디테일 요청문 초안: `evals/benchmark/fidelity/`에 요청문 6개(앱 3·웹 3), 낱개 요구 114개, 수정 요청 12개. 아직 어떤 생성물에도 돌려 보지 않았다.
- 조사 결과를 검토하며 직접 확인한 것: 패턴 CSS 53개 중 `var(--motion-…)` 참조 0개, `outline-offset` 8가지, 화면 전환 토큰 420ms와 `page-transition` 기본 280ms의 어긋남, 적색·녹색 색각 이상에서 오류 빨강과 완료 초록의 OKLab 거리 0.271 → 0.113, 편집 후 검사 훅의 warn 안내에 "사용자가 명시한 값" 언급이 없는 것.
- `scripts/lib/runArchive.ts`(순수 로직, 테스트 먼저 10개): 대화 기록에서 도구 사용 순서만 뽑기(`traceOf`, 실행한 사람의 폴더 경로는 지움), 읽은 스킬 문서 목록(`docsReadOf`), 남길 파일 고르기(`keepFile`), 묶기·풀기(`bundleOf`·`restorePlan`, 폴더 밖 경로가 든 묶음은 풀지 않음).
- `scripts/benchmark/archive.mjs`: 묶기(`--out`·`--name` → `evals/benchmark/artifacts/<이름>.json.gz`), 보기(`--list`), 풀기(`--restore`, 이미 `runs/`가 있는 폴더에는 풀지 않음).
- 가짜 실행 폴더 2개로 묶기 → 보기 → 풀기 → `measure.mjs` 측정·캡처까지 돌려 확인했다. 푼 `index.html`은 원본과 같았고, 묶음 안에 실행 폴더 경로가 남지 않았다.
- `docs/benchmark.md`·`benchmark.en.md`의 "다시 돌리기"에 보존 단계와 절 하나를 더했다.
- 화면 결과를 바꾸는 작업이 아니라서 AS-IS/TO-BE 이미지는 만들지 않았다(규칙 12).

## 3. 주의사항

- 실제 claude CLI 실행으로 만든 폴더로는 아직 묶어 보지 않았다. 다음 측정(요구 충족률 시험 실행)에서 처음 쓴다.
- 묶음은 저장소에 들어가고, 저장소 루트가 곧 플러그인이라 설치 크기에 더해진다. 산출물은 압축하면 실행당 수십 KB로 예상하지만 재지 않았다. 묶음이 커지면 보관 위치를 다시 정한다.
- 대화 기록 전체는 남기지 않는다. 모델의 생각·응답 글을 다시 봐야 하는 분석은 이 묶음으로 할 수 없다.
- 조사 문서의 브라우저 지원 수치와 2차 출처로만 확인한 값은 구현 전에 다시 확인한다. 각 문서의 "확인하지 못한 것" 절에 목록이 있다.
- 사용자 결정이 남은 것: 요구 충족률 본측정 비용(약 120달러), 진입·스크롤 모션을 요청 없이도 기본으로 넣을지, 화면 밖으로 나가는 요소의 가속 곡선, 색 방향(어두운 테마·색각 이상 검사·근거 표기).
