# suta 0.19.0

suta 0.19.0 finishes the pattern review started in 0.18.0 and corrects two things that the 0.18.0 measurement got wrong.

- **All 53 component patterns now document states and edge cases.** The remaining 31 patterns (gestures, transitions, progress and feedback, navigation and surfaces) were read against their code, and gaps were fixed with tests (1,092 → 1,297 tests).
  - pull-to-refresh did not work on touch: the browser cancelled the gesture after about 22px.
  - edge-swipe-back swallowed taps on buttons within 24px of the edge.
  - swipe-to-delete and drag-to-reorder treated a cancelled gesture as a release, deleting the row or committing the order.
  - long-press-menu did not open with Enter or Space. hamburger-menu, zoom-lightbox, card-expand and the swipe viewer did not move, trap or restore focus.
  - enter-exit left an initially shown element transparent under React StrictMode. scroll-reveal never revealed elements taller than the viewport.
  - count-up jumped when the value changed mid-animation. virtual-list rendered missing indexes when the item count shrank.
  - range-slider returned an off-grid value when `step` did not divide the range. file-upload flickered previews on every progress update and accepted zero-byte files.
- **The design order is now in the always-read procedure.** In the 0.18.0 measurement the new `design.md` was opened in 0 of 6 runs, even after the procedure said "read it". The six screen jobs and the decision, evidence and reference split now live in `SKILL.md`.
- **Selected state.** Choice chips and cards are white with a 1px border, since gray fills read as disabled. The chosen one adds a check mark or bold text to the accent color. Multi-line notices and their consent checkbox go in one gray box.
- **Layer fixes.**
  - A second bottom sheet's scrim now covers the first sheet. The sheet and its backdrop share one `z-index` and stack in document order.
  - sticky-header defaults to a light surface with a text color (`--header-color`), instead of a dark background with no text color.
- Pattern defaults that were still blue-gray now use the color tokens.

## What the measurements say

Three requests that match no screen convention, 2 runs per condition, blind judgments against 0.17 (default model, other model):

| Version | Judgments (version : 0.17) |
|---|---|
| 0.18.0 | 8 : 4, 9 : 3 |
| 0.18.0 with the design order moved into `SKILL.md` | 6 : 6, 6 : 6 |
| After the selected-state fix, waitlist sign-up only | 3 : 1, 3 : 1 (was 1 : 3, 0 : 4) |

- There is not yet evidence that the design order and detail documents improve generated screens over 0.17. With two runs per condition the gap between the first two rows may be chance.
- The selected-state fix moved the one request it targeted. The direction is clear; the size is not.
- On a request with a sort menu, a filter sheet and a tab bar, both 0.17 and the current version built the layers correctly. The elevation standard fixed defects in the pattern code, not in generated screens.

## Behavior changes

If you copy these patterns again, note the following.

- `swipe-to-delete`: pressing the content of an open row closes it.
- `zoom-lightbox`: the backdrop is a full-screen `<button>` instead of a `<div>` (same class).
- `scroll-reveal`: the observer `threshold` is now `[0, threshold]`.
- `useSpring`: with reduced motion on, `to()` jumps to the target. Pass `respectReducedMotion: false` for the old behavior.
- `file-upload`: zero-byte files and re-selected duplicates are rejected (`empty`, `duplicate`).
- `sticky-header`: the default background is light. Dark screens set `--header-bg` and `--header-color`.
- `bottom-sheet`: the sheet's `z-index` equals its backdrop's. Render a later sheet after the earlier one in the document.

Checked in headless Chromium only. Screen readers, iOS, Android and Safari were not tested.

## Install

Claude Code, in the chat:

```text
/plugin marketplace add Guksu/suta
/plugin install suta@suta
```

Codex, in a terminal:

```bash
codex plugin marketplace add Guksu/suta
codex plugin add suta@suta
```

Approve suta's post-edit check in Codex `/hooks`.

Skill only, without the post-edit hook:

```bash
npx skills add Guksu/suta --skill suta
```

## Update

For Claude Code, run `claude plugin marketplace update suta` followed by `claude plugin update suta@suta`, then start a new session.

For Codex, run `codex plugin marketplace upgrade suta`, then check and update the installed suta version in the app's plugin settings. Marketplace refresh alone does not confirm an installed-plugin update.

For a skills CLI install, run `npx skills update suta` from the project where you installed it; select the scope where suta is installed. If you used our install script, rerun it with the same destination.

These commands follow the current marketplace branch. The source archive on this release preserves version 0.19.0.
