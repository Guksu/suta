# suta 0.14.0

suta 0.14.0 includes three versions since 0.11.0: React Native checks (0.12), color, font and copy guidance (0.13), and settings and landing page conventions (0.14).

- **React Native:** the layout check reads `StyleSheet.create` values. The motion check reads Reanimated and React Native `Animated`. A new guide maps the web patterns to native components.
- **Color:** neutral tokens are now pure gray. A palette tool (`scripts/palette.mjs`) turns one accent color into a full set that meets contrast without rounding.
- **Fonts and copy:** a `--font-sans` token, heading wrap guidance, and a new copy guide for buttons, dialogs, errors, empty states and toasts.
- **Settings screens:** full-width lists, accent-colored switches, and theme rows that show the current value. Based on 161 settings screens from 30 apps.
- **Landing pages:** a proof band, a product picture for each feature, testimonials and a closing call to action. Product pictures are marked `role="img"`, stay inside their container and switch to a one-column picture on mobile. Based on 42 SaaS and service websites.
- **7 new layout check rules:** `muddy-accent`, `neutral-temperature`, `accent-contrast`, `meta-copy`, `mixed-tone`, `numbered-markers` and `interactive-in-picture`.

We re-ran the same requests with each new version. From 0.12 to 0.13, muddy accent colors went from 6 to 0 and bluish gray text from 10 to 0. From 0.13 to 0.14, the final landing page round won 6 of 6 blind comparisons. Settings lost 2 to 4 twice: the judges preferred the rounded-card template that most reference apps do not use.

Against Claude Code without suta, on four requests run twice each, suta 0.14 removed the blue and violet accents (8 runs to 1), gradients and large shadows (12 to 1) and most accessibility violations (16 to 1). Blind judges split 9:7 and 7:9: suta won the dashboard and landing page and lost settings and login. These are small samples; see the [screen comparisons](https://github.com/Guksu/suta/blob/v0.14.0/docs/comparisons.en.md) for limitations.

Validation: build, lint, 807 tests and 476 selection checks passed. The pattern audit reported no errors or warnings. The existing bundle-size warning remains.

## Install

Claude Code, in the chat:

```text
/plugin marketplace add Guksu/suta
/plugin install suta@suta
```

Codex, in a terminal:

```bash
codex plugin marketplace add Guksu/suta
codex plugin add suta@suta
```

Approve suta's post-edit check in Codex `/hooks`.

Skill only, without the post-edit hook:

```bash
npx skills add Guksu/suta --skill suta
```

## Update

For Claude Code, run `claude plugin marketplace update suta` followed by `claude plugin update suta@suta`, then start a new session.

For Codex, run `codex plugin marketplace upgrade suta`, then check and update the installed suta version in the app's plugin settings. Marketplace refresh alone does not confirm an installed-plugin update.

For a skills CLI install, run `npx skills update suta` from the project where you installed it; select the scope where suta is installed. If you used our install script, rerun it with the same destination.

These commands follow the current marketplace branch. The source archive on this release preserves version 0.14.0.
