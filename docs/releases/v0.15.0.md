# suta 0.15.0

suta 0.15.0 is about mobile app screens. Well-made apps keep the UI close to neutral, but photos, banners, category pictures and logos carry color and density. suta 0.14 kept the UI neutral and also left those content slots empty.

- **Content art:** `content-art.css` fills photo slots when no real photo exists yet. It has 14 scenes (a noodle bowl, a plate on a table for menus and stores, rooms, landscapes, products and more), a logo mark and a shortcut tile, in 7 palettes. The layout check does not count these colors as UI colors.
- **Illustrated icons:** 57 colored flat icons (`illustrations.ts`, React `Illustration.tsx`, from Microsoft Fluent Emoji Flat under MIT) for large content slots such as category shortcuts, banners and stand-in store photos. List rows and the frame keep line icons.
- **Line icons:** 52 to 72. New food categories, clothing and transaction categories (transit, card, transfer, groceries, phone, savings, deposit, bank).
- **Screen conventions:** new sections for content art, page dots, one-to-one chat, notifications, photo profile and banking home, plus details for delivery home, stay detail and onboarding. Based on 194 screens from 30 reference apps and app store screenshots of 16 apps.
- **3 new layout check rules:**
  - `stacked-icon-buttons` catches icon buttons that stack vertically.
  - `grid-blowout` catches full-height grid frames with no column defined. The default width of an input then pushes the frame wider than the screen.
  - `hidden-text-escape` catches screen-reader text that leaks out of an unpositioned scroll area and lengthens the page.
- **carousel:** dot buttons now have a 24px touch target in the pattern CSS.

We ran eight app-screen requests (feed, delivery home, stay detail, chat, notifications, profile, onboarding, banking home) twice per condition. suta 0.14 lost the blind comparisons 4:12 and 3:13. After six rounds of fixes, suta 0.15 won 19:13 and 20:12 against Claude Code without suta.

Compared with the runs without suta:

- Emoji went from 80 to 0.
- Accessibility violations went from 232 to 17.
- Text under 12px went from 97 to 0, and touch targets under 24px from 17 to 0.
- Screens overflowing at 320px went from 1 to 0.

Chat went from 0:4 to 3:1 once the two new render rules caught its overflow and empty-space bugs. Stay detail, onboarding and notifications still lost. These are small samples; see the [screen comparisons](https://github.com/Guksu/suta/blob/v0.15.0/docs/comparisons.en.md) for limitations.

Validation: build, lint, 825 tests and 476 selection checks passed. The pattern audit reported no errors or warnings. The existing bundle-size warning remains.

## Install

Claude Code, in the chat:

```text
/plugin marketplace add Guksu/suta
/plugin install suta@suta
```

Codex, in a terminal:

```bash
codex plugin marketplace add Guksu/suta
codex plugin add suta@suta
```

Approve suta's post-edit check in Codex `/hooks`.

Skill only, without the post-edit hook:

```bash
npx skills add Guksu/suta --skill suta
```

## Update

For Claude Code, run `claude plugin marketplace update suta` followed by `claude plugin update suta@suta`, then start a new session.

For Codex, run `codex plugin marketplace upgrade suta`, then check and update the installed suta version in the app's plugin settings. Marketplace refresh alone does not confirm an installed-plugin update.

For a skills CLI install, run `npx skills update suta` from the project where you installed it; select the scope where suta is installed. If you used our install script, rerun it with the same destination.

These commands follow the current marketplace branch. The source archive on this release preserves version 0.15.0.
