# suta 0.10.0

This is the first GitHub release of suta. It packages the existing 0.10.0 version, including 56 UI patterns, layout/color/motion guidelines and plugin checks for Claude Code and Codex.

Compared with 0.9:

- Added stock trading screen guidelines for order panels, search and mobile buy/sell controls.
- Added rise/fall color tokens with at least 4.5:1 contrast on the tested light backgrounds.
- Excluded semantic rise/fall colors from the color-count warning.
- Added a desktop comparison with the requests, screenshots and per-run measurements.

The [stock trading study](https://github.com/Guksu/suta/blob/v0.10.0/docs/research/2026-10-09-securities-web.md) records the method and limitations. Results come from a small number of runs and do not guarantee the same outcome in another project.

## Install

Claude Code, in the chat:

```text
/plugin marketplace add Guksu/suta
/plugin install suta@suta
```

Codex, in a terminal:

```bash
codex plugin marketplace add Guksu/suta
codex plugin add suta@suta
```

Approve suta's post-edit check in Codex `/hooks`.

Skill only, without the post-edit hook:

```bash
npx skills add Guksu/suta --skill suta
```

## Update

For Claude Code, run `claude plugin marketplace update suta` followed by `claude plugin update suta@suta`, then start a new session.

For Codex, run `codex plugin marketplace upgrade suta`, then check and update the installed suta version in the app's plugin settings. Marketplace refresh alone does not confirm an installed-plugin update.

For a skills CLI install, run `npx skills update suta` from the project where you installed it; select the scope where suta is installed. If you used our install script, rerun it with the same destination.

These commands follow the current marketplace branch. The source archive on this release preserves version 0.10.0.
